## 试一试 {span=2}

1. 点右上角的 **标注** 按钮，打开块标注模式。
2. 点下面「发布说明草稿」里的任意一段、一项或表格。
3. 选一种类型：建议、保留、疑问、关注，可以再写一句批注。
4. 点 **回复** → **复制回复**，粘贴回和 Agent 的对话。

```callout info 标注会保留
标注显示在块上，刷新页面后还在；回复里会出现「标注」一节，引用被标注块的开头。
```

## 发回给 Agent 的样子

```markdown
# Re: 用「标注」把意见发回给 Agent（示例数据）

## 标注
- **C · 建议** "新版本支持批量导出，一次最多 500 条"
  > 写清楚超过 500 条时会怎样
- **C · 疑问** "导出格式：CSV、XLSX"
  > 要不要支持 JSON？
- **C · 保留** "旧的单条导出入口继续保留一个版本"

_以 ">" 开头的行是读者输入的文字。_
```

## 发布说明草稿（示例数据） {span=3}

新版本支持批量导出，一次最多 500 条。

导出在后台进行，完成后在通知里给出下载链接，链接 24 小时内有效。

- 导出格式：CSV、XLSX
- 可以按项目、状态和时间范围筛选
- 旧的单条导出入口继续保留一个版本

| 项目 | 旧版 | 新版 |
| --- | --- | --- |
| 单次条数 | 1 | 500 |
| 方式 | 同步下载 | 后台任务 + 通知 |
