# AntV Infographic gallery

A Vite + React showcase of SVG infographic templates powered by the real MIT library [`@antv/infographic`](https://github.com/antvis/Infographic) (~200 built-in templates). Pick a curated template, preview the live SVG, and copy the declarative DSL.

## Run

```bash
bun install
bun run dev
```

Open `http://localhost:5173/antv-infographic/`.

## Stack

- `@antv/infographic` (MIT) — SVG rendering + template DSL
- Vite, React 19, TypeScript, Tailwind v4, shadcn/ui (radix-nova)
