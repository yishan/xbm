# snapcn 产品演示组件

Remotion 产品演示视频组件（AI 回答流、终端、手机外壳、卡拉 OK 字幕、标题揭示），源码复制自 snapcn 注册表，用 Remotion Player 在浏览器里实时预览，跟随系统深浅色。

- 来源：[shadcn-labs/snapcn](https://github.com/shadcn-labs/snapcn)（MIT，© Shadcn Labs，见 `src/components/snap-cn/LICENSE-snapcn`）· [snapcn.dev](https://snapcn.dev)
- Remotion 固定为 `4.0.473`（满足 3 天发布期限制），仅使用免费的 `@remotion/player` 浏览器预览，不涉及渲染服务或付费功能；未使用 `@snapcn/mcp`。
- 所有文案均为示例数据。

```bash
bun install && bun run dev   # http://localhost:5173/snapcn/
```
