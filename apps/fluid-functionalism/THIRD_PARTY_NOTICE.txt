src/components/ui/button-radix.tsx is the Radix flavor of Button from
registry/radix/button.tsx in the same repository. The registry installs the
Radix and Base UI flavors onto the same filenames, so only Button is vendored
beside the Base UI board.

Inter is loaded from @fontsource-variable/inter (SIL Open Font License).
pdfjs-dist is a dependency of the upstream file-thumbnail component and is not
used unless a message is given a file.
