# Fluid Functionalism

用注册表里的按钮、对话框、选择、分页、开关、滑块和消息，当场调节弹簧速度、强调色、接近高亮、表面层级和密度，再复制当前主题。

组件来自 [Fluid Functionalism](https://fluidfunctionalism.com)（[mickadesign/fluid-functionalism](https://github.com/mickadesign/fluid-functionalism)，MIT，© 2026 Micka Touillaud）。名称归原作者，这里不用它的标志。

运行：`bun install && bun run dev`，打开 http://localhost:5173/fluid-functionalism/。板上的句子都是示例数据。
