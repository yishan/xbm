# figures4papers

Single-user MVP for paper-style scientific figures (bar, radar, line), editable sample metrics, and PNG export.

Inspired by [ChenLiu-1996/figures4papers](https://github.com/ChenLiu-1996/figures4papers).

## Run

```bash
bun install
bun run dev
```

## Stack

Bun + Vite + React + TypeScript + shadcn/ui + Recharts + html-to-image

See [PLAN.md](./PLAN.md) for scope.
