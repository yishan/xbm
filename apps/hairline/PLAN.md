# Hairline — 组件与协作实验室

目标：让一个用户体验全部 19 个 Hairline 图形，并理解三个模拟助手的任务交接。

## MVP
- 7 类 / 19 图形，单个交互台切换，中文说明和实时读数。
- 明暗 / 跟随系统主题、0–1 强度、键盘提示、移动端与减少动态效果。
- Dicembre 规划 → Grok 审阅 → Muse 执行；开始、暂停、单步、重置和交接记录。
- 明确本地模拟，不连接产品账号，不调用外部 agent。
- 本地 lint/build、全仓 build、浏览器检查与截图/视频。

## 任务
1. 官方 Vite React/TS 模板，Bun 安装安全年龄门槛，shadcn minimalist 控件。
2. 核对 Hairline 版本、19 个导出、分类、交互与 MIT 许可。
3. 组件体验台：仅挂载当前图形，读数限频，说明与主题同步。
4. 协作状态机：不可跳步，重复开始不创建并行时钟，重置清除时钟与记录。
5. 窄屏、主题、所有图形与状态回归；保留证据。

## 技术
Vite + React + TypeScript：沿用兄弟 app。Bun：仓库规定。Hairline React 入口：直接使用官方组件。shadcn/ui 按需控件：一致的控件语义。纯前端：演示无需后端。细线、纸白与墨黑、橙色信号：让图形与交接关系成为主视觉。

## 延后
真实账号集成、多用户、持久化、AI 调用与部署均不属于本地演示范围。不会修改共享配置、tracking 或其他 apps。
