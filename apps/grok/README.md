# 我怎么用 Grok Bot

一页 ASCII / 终端风格的分享稿：17 个各管一件事的 bot 的一天时间线、按小组分组的卡片、四条协作流程和设计取舍。纯静态单页，跟随系统深浅色，适合投影。

## Run

```bash
bun install && bun run dev   # http://localhost:5173/grok/
```

Content is Yishan's own setup (not a bookmark pick). No external network requests; fonts are the system monospace stack.
